# What changed in this pass

Everything below was actually implemented in the code (not just proposed), verified with `npm run build` (clean) and `npm run lint` (no new issues, the pre-existing lint items are all in files untouched here). A few items from our discussion were already done before this session started (mobile bottom tab bar, header/footer mobile layout, background-effect cleanup, cursor glow) — this file covers what changed in this specific pass.

## Structural
- **Home.tsx fully rebuilt**: hero (name always visible, no hover-gate, 3 CTAs), trust-bar marquee, services preview (4 cards, 2-up mobile), pricing preview (4 tiers, 2-up mobile, package-aware links), about teaser, FAQ, and a repeated CTA pattern through the page instead of one CTA at the very bottom.
- **Duplicate project showcase removed**: the 3-card grid + sphere gallery both showing the same projects is gone. One `FeaturedWorkCarousel` (2-3 flagship projects, auto-advancing) is now the primary homepage showcase. The sphere gallery is kept as a secondary "explore" widget, now mixing in real result numbers and problem-prompt cards (see `PROBLEM_PROMPTS`/`RESULT_HIGHLIGHTS` in `content.ts`), each routing somewhere different (project, project, or service page).
- **Projects and Services list pages** rewritten as a vertical, full-width, hover-expand row list (`VerticalShowcaseList.tsx`), each row shows category, result metric, and a visual at a glance, click-through only for full detail.
- **Contact page is calendar-first**: the week-view calendar is the default view, not collapsed behind an accordion. A mode toggle switches to a message-only form. Arriving from a Pricing tier (`?package=growth`) pre-fills the message with that context.
- **Pricing page and homepage pricing preview**: package "Get Started" buttons link to `/contact?package=<tier>` so the tier context carries through instead of a blank form.

## Round 3 (this pass)

- **Horizontal scroll bug found and fixed at the root.** `VerticalShowcaseList`'s hover-preview panel was positioned relative to its own list container (`absolute -right-6 translate-x-full`), so on any viewport narrower than the list's own margin plus the panel's width, part of the panel landed past the edge of the screen and put a horizontal scrollbar on the ENTIRE site, not just that component. Rewired it to `fixed` against the viewport's own right edge instead, which structurally can't do that, plus added a defensive `overflow-x: hidden` on `html`/`body` so a future mistake like this is invisible instead of site-wide. Confirmed via headless browser: `document.documentElement.scrollWidth === clientWidth` on both Home and Contact.
- **Sphere gallery fixed for real**: bigger (`size` raised, container height raised to 520-640px depending on page), and its content is now Services + customer-problem prompts instead of duplicating the Projects list sitting right above it, each node routes to the matching service page.
- **Contact page background actually interactive now.** Same root cause as the homepage water fix from last round: `DitherReveal`'s pointer listeners were bound to its own container, which sits in a `fixed inset-0 -z-[3]` wrapper behind the whole page (there was also a dark overlay div painted directly in front of it in the same wrapper). Moved the listeners to `window`, confirmed with a scripted mouse move that the reveal now tracks it.
- **Inline "dropdown" expand added** to both Projects and Services lists: a "Quick look / What you get" toggle reveals detail bullets (project outcomes, service deliverables) in place, no navigation required, "View full case study / Full details" stays as a separate, explicit link for anyone who wants the full page. - **Delve-style stacked sections built and verified working.** Home now has three full-viewport `sticky top-0` sections (Projects, Services, Pricing) with increasing z-index and solid backgrounds, a pure-CSS technique, no scroll-hijacking JS. Confirmed with screenshots at five scroll depths: the dark Services panel visibly slides up and covers the Projects panel, then the light Pricing panel covers Services in turn, exactly the "next section comes up and covers the last" effect requested.
- **Pricing format changed sitewide** to always carry a trailing "+", e.g. `$140–$415+`, previously only the Commerce tier (the one without a real ceiling) got a "+".
- **5 more currencies added**: CAD, AED, HKD, JPY, INR, on top of the existing six.
- **Retainer/add-on pricing reframed with a cost anchor.** Every add-on in `ADDONS` now carries an illustrative `costAnchor` line (e.g. "a dedicated content coordinator commonly runs 500-800 USD/month elsewhere, this is a fraction of that, and it's month to month") plus a plain disclaimer that these are ballpark comparisons, not a quote, confirmed on the free call. This was explicitly requested as "style, not literal numbers", the figures used are illustrative market ranges, not commitments.
- **Two flagship case studies sharpened** (De Fabiano, Gratia Dev Command Center) to foreground the product-catalog/inventory and pipeline/dashboard/workflow angles specifically, since those were called out as the details most likely to land with a business-owner reader. No new work was invented, this re-frames real, already-listed work to answer the question a prospect in that situation would actually ask.

## Round 5 (this pass)

- **Found and fixed the real reason the scroll-stacking effect stopped working.** It wasn't a layout bug, it was Framer Motion: the page-level wrapper's `animate={{ y: 0 }}` leaves a permanent `transform: translateY(0px)` on that element even once the animation finishes, and a `transform` on any ancestor breaks `position: sticky` for everything inside it (a well-documented CSS interaction, not obvious from the outside). Dropped the `y` from Home's page-transition wrapper, kept the opacity fade, confirmed with screenshots that Services genuinely slides up and covers Projects again.
- **Removed the `overflow-x: hidden` safety net** added a couple of rounds back. It was very likely a second contributing factor to the sticky bug (overflow on an ancestor can also interfere with sticky positioning in some browsers), and it's no longer needed since the actual overflow source (the old floating hover panel) was already fixed at the root.
- **Brick effect interactivity fixed**, same root cause and same fix as the water and dither backgrounds before it: listeners were bound to the container, which can end up behind other content depending on what's layered on top; moved to `window`.
- **Hero photo replaced** with the one supplied, compressed from 5MB to a proper web-weight JPEG (`public/images/hero/jimmy-hero.jpg`), set as the primary rotation image. Brick tint adjusted to a warmer tone (`#b8935a`) closer to the wood tones in the photo.
- **Sphere gallery simplified**: dropped the "services and problems" mix and its confusing headline, it's services only now, with bigger cards (`size` raised to 58) and a stronger hover pull (`hover` raised to 220) so individual services are actually readable and clickable.
- **Currency now auto-detects from the browser's own locale** (`navigator.language`) on first visit, covering all 11 currencies already on the site, and falls back to USD for anything unmapped, exactly as asked. A manual override still works and is remembered after that.
- **Pricing removed from every marketing-facing page.** `/pricing` is now "Service Packages", full feature lists per tier, zero dollar figures, every CTA goes to "Ask About This" or "Book a Free Discovery Call" instead of a price-anchored button. Home's matching stacked panel updated the same way. The add-on cost-anchor lines stay (they cite what hiring someone else would typically cost, not Jimmy's own rate, so they inform without pricing the work). **Left untouched on purpose**: `Quote.tsx`, which is a whole interactive estimator built around producing a number, gutting its numeric core is a materially bigger job than reframing marketing copy and deserves an explicit decision rather than a guess, flagging it here for that decision.
- **Section colors strengthened** across the three stacked Home panels for actual visual distinction: a cool light grey-blue for Projects (`#eef1f4`), unchanged dark navy for Services, and a warm amber (`#e3a869`) for Packages, a deliberate light/dark/light-warm rhythm instead of two panels that read as nearly the same shade of cream.
- **Hover effect made substantially bigger**, per "almost a full page": active-row padding roughly doubled, the title jumps to `text-6xl` on desktop, the full detail list renders in a two-column grid instead of being capped at 3 bullets, confirmed with a screenshot showing the expanded row taking up most of the viewport.
